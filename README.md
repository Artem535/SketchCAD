# SketchCAD

Tablet-first parametric CAD, using C++20, Qt Quick and Ceres/Eigen. OCCT follows the sketcher milestone. Distribution: pay what you want; software license remains undecided.

The first prototype is a constrained rectangle with editable dimensions, translation, anchoring and rollback on conflicts. Android readiness is not yet validated.

See [prototype specification](docs/modules/ROOT/pages/prototype.adoc), [implementation plan](docs/modules/ROOT/pages/implementation-plan.adoc) and [build instructions](docs/modules/ROOT/pages/build.adoc). Dependencies use the pinned vcpkg manifest; Qt is supplied by your Qt SDK.
