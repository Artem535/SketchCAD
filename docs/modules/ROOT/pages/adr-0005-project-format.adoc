= ADR-0005: Формат проекта 2D-эскиза
:toc:

Статус:: Принято пользователем 18 октября 2026 года; реализация не начата.
Задача:: https://github.com/Artem535/SketchCAD/issues/13[#13], F01.
Контракт:: xref:project-format.adoc[].

== Контекст

После завершения редактирования эскизов следующий шаг 0.1 — сохранить результат между запусками.
Нужны переносимость, точное восстановление ID, ограничений и размещения размеров и безопасная запись.
Выбор формата надолго становится обязательством совместимости; память объекта C++ и Qt-типов им не является.

== Предлагаемое решение

* Один UTF-8 JSON-файл `.sketchcad`, схема v1 с явным идентификатором формата и единицами мм.
* Геометрия, ограничения и счётчик ID сохраняются полностью. История Undo/Redo и настройки интерфейса не сохраняются.
* uint64 ID и ревизии кодируются десятичными строками, чтобы инструменты с double-числами не обрезали большие значения.
* Строгая проверка схемы и ссылок; новая версия отклоняется с понятным сообщением. Несогласованные с ограничениями
  координаты не исправляются незаметно при чтении.
* Кодек и валидация — в ядре без Qt, nlohmann-json подключается через vcpkg. Qt отвечает за пути и QSaveFile.
* Успешная атомарная замена файла предшествует сбросу признака несохранённых изменений. Ошибка открытия не меняет документ.

== Альтернативы

* ZIP-контейнер нужен для будущих вложений, но в 0.1 их нет: добавляет сложность без пользы для текущего эскиза.
* Бинарный формат компактнее, но хуже проверяется вручную; требует отдельной схемы и инструментов диагностики.
* QJsonDocument связывает кодек с Qt и нарушает границу ядра. Самописный JSON-парсер создаёт лишнюю ответственность.
* Числовые uint64 в JSON допустимы для некоторых парсеров, но небезопасны для обмена с инструментами на JavaScript.

== Последствия

Нужен валидируемый снимок модели с исходными ID и watermark, а также замена документа с сохранением solver hook.
Проверка файла обязана сохранять геометрию и ранее сохранённый файл при любой ошибке. Будущие изменения схемы
потребуют явных миграций с fixtures; будущая упаковка в контейнер — отдельного решения. Поддержку Android необходимо
проверять на устройстве отдельно, включая storage provider. Автосохранение и восстановление остаются F02.
