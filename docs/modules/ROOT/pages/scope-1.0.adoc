= Scope 1.0: параметрический механический CAD
:toc:

Все перечисленные требования обязательны для 1.0 на Android, Linux и Windows.
Каждое требует последующей подробной service/module specification и связанных issues перед кодом.

[cols="1,2,4",options="header"]
|===
|ID |Объём |Критерий приёмки
|R10-SKETCH |Полный Sketcher |Набор 0.1 плюс эллипсы, сплайны, offset, зеркало, массивы, проецирование модели, управляющие/справочные размеры; каждый инструмент проверен отдельным сценарием.
|R10-TEXT |Текст и подложка |Текст преобразуется в рабочие контуры; изображение можно калибровать по известному размеру и использовать для ручного обведения. OCR/автовекторизация не входят.
|R10-SOLVER |Диагностика и drag |DOF, конфликты и избыточность проверены, в том числе на вырожденных случаях; мягкая drag-цель не нарушает hard constraints; численная неопределённость обозначена явно.
|R10-FEATURE |Несколько тел и операции |Extrude, revolve, sweep, loft, boolean, fillet, chamfer, shell, draft, holes, mirror и patterns имеют параметры, историю и корректное перестроение тестовых деталей.
|R10-PARAM |Параметры и зависимости |Именованные параметры, формулы с единицами, межэскизные/междетальные ссылки, подавление и перестановка операций; недопустимые зависимости диагностируются.
|R10-REBUILD |Ошибки истории |Последнее корректное состояние сохраняется; сломанная операция и зависимые элементы отмечены, ссылки можно восстановить; нет тихой перепривязки к другой грани.
|R10-DIRECT |Прямое редактирование |Импортированные и собственные B-Rep: move/rotate faces, offset, delete/heal faces, изменение отверстий; изменения входят в историю и Undo/Redo.
|R10-ASSEMBLY |Компоненты и подсборки |Детали/вложенные подсборки, фиксация, совпадение, соосность, параллельность, перпендикулярность, расстояние и угол; DOF/конфликты диагностируются; компоненты можно перемещать в допустимых положениях.
|R10-CHECK |Проверки и состав |Пересечения обнаруживаются на эталонных сборках; формируется согласованная спецификация состава и позиции.
|R10-DRAW |Ассоциативные чертежи деталей/сборок |Проекции, разрезы, местные виды, скрытые/осевые линии, размеры и допуски, geometric tolerances, шероховатость, резьба, сварные обозначения, основные надписи, позиции/таблицы; обновление модели отражается на чертеже, потерянные привязки обозначены.
|R10-STANDARD |ЕСКД и ISO |Есть явная матрица поддерживаемых элементов, шаблоны/настройки и проверяемые образцы. Полное соответствие всем стандартам не заявляется.
|R10-EXCHANGE |Обмен |STEP/IGES для геометрии и доступной структуры, STL/3MF для печати, DXF для 2D, PDF для чертежей. Матрица import/export и fidelity должна быть утверждена перед реализацией; round-trip проверяется независимыми потребителями.
|R10-IMPORT |Граница импорта |STEP/IGES не восстанавливают исходную feature history; доступная структура сохраняется. STL/3MF остаются сетками для просмотра, измерения и размещения; автоматическая параметризация сеток не обещана.
|R10-MEASURE |Единицы и свойства |mm/in и выражения с единицами, расстояния/углы, объём/площадь/масса; масса использует назначенную плотность. Материалы дают физические свойства и простое отображение.
|R10-MACRO |Python-макросы |Embedded CPython, стандартная библиотека и API SketchCAD на трёх платформах. Макрос создаёт обычные операции истории через транзакции; ошибка откатывается. Поддержка arbitrary pip/native packages и code-on-rebuild features не обещана.
|R10-PROJECT |Хранение |Внешние ссылки и самодостаточная упаковка проекта; autosave/recovery, потерянные ссылки и обновления внешних деталей диагностируются; обновление применяется по команде пользователя.
|R10-COMPAT |Совместимость |Чтение старых проектов через явную миграцию и резервную копию; неизвестная новая версия не перезаписывается молча.
|R10-SCALE |Масштаб испытаний |Ориентир: 100 уникальных деталей / 500 экземпляров; наборы и budgets задаются после выбора устройств. Это не уже подтверждённый benchmark.
|R10-PLATFORM |Полный автономный продукт |Функции доступны без аккаунта/сети на Android ARM64, Linux/Windows x86-64; touch/stylus и mouse/keyboard, RU/EN проверены.
|R10-DIST |Распространение и диагностика |APK напрямую, Linux packages, Windows installer; Google Play дополнителен. Проверка обновлений по настройке, установка с подтверждением; crash reports только добровольно.
|===

== Сквозные сценарии
* Параметрическая деталь: создать профиль, построить тело, использовать поддерживаемые features, изменить исходные параметры, проверить перестроение, сохранить/открыть и обменять STEP.
* Импорт: открыть B-Rep без исходной истории, изменить грани, отменить/повторить и экспортировать.
* Сборка: детали и подсборка, связи, допустимое перемещение, пересечения и состав.
* Чертёж: виды/разрезы/размеры и обозначения, изменение модели, обработка потерянной привязки, PDF.
* Макрос: создать обычные операции, отменить, проверить rollback исключения и повторить на Android/Desktop.

== После 1.0
Листовой металл, свободные поверхности, CAM, прочностные расчёты, фотореалистичный рендеринг,
облачная совместная работа, AI-помощник, временная симуляция/приводы/физика механизмов,
автовекторизация, восстановление истории импорта, параметризация сеток.
DWG и нативные форматы других CAD требуют отдельного решения после проверки библиотек/лицензий.
Глубокая замена UI бинарными плагинами и собственные скриптовые features не входят в согласованную 1.0.
