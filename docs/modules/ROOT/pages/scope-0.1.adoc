= Scope 0.1: самостоятельный 2D Sketcher
:toc:

Согласованная граница первого полезного релиза. Текущий rectangle demo — технический этап 0, не готовая 0.1.

[cols="1,2,4",options="header"]
|===
|ID |Требование |Критерий приёмки
|S01-GEO |Точки, линии/полилинии, прямоугольники, окружности, дуги |Пользователь создаёт, выбирает, меняет и удаляет каждый тип; сохраняются стабильные ID и корректные ссылки.
|S01-EDIT |Вспомогательная геометрия, привязки, trim/extend |Можно построить замкнутый профиль, обрезать и продлить элементы; вспомогательная геометрия не попадает в профиль как рабочая.
|S01-CON |Совпадение, горизонтальность/вертикальность, параллельность, перпендикулярность, касание, равенство, фиксация |Для каждого типа есть независимые позитивные/конфликтные сценарии; после решения проверены hard residuals.
|S01-DIM |Длина, расстояние, угол, радиус |Размер изменяет зависимую геометрию; некорректные значения отклоняются без повреждения проекта.
|S01-DRAG |Перетаскивание с сохранением ограничений |Касание/мышь перемещают допустимые DOF; hard constraints сохраняются, конфликтная операция откатывается.
|S01-DIAG |DOF и выделение конфликтующих ограничений |Недоопределённые/полностью определённые тестовые эскизы показывают верный локальный DOF; конфликт виден в UI. Неопределённая численная ошибка отличается от доказанного конфликта; минимальный конфликтный набор не обещан.
|S01-UNDO |Undo/Redo |Создание, удаление, constraints, размеры и перенос можно отменять/повторять; неуспешная команда не оставляет частичных изменений.
|S01-FILE |Сохранение/открытие, автосохранение и восстановление |После открытия сохраняются геометрия, ID, constraints и размеры; восстановление после моделируемого сбоя проверено.
|S01-DXF |Экспорт геометрии DXF в миллиметрах |Линии, окружности и дуги открываются с корректным масштабом в независимом потребителе; constraints/размеры остаются в собственном проекте, листы чертежа не экспортируются.
|S01-UI |Навигация, Android/Desktop input и RU/EN |Pan/zoom, выбор, ввод точных размеров и drag проверены на Android-планшете и Linux/Windows.
|S01-REL |Переносимость и совместимость |Один проект проходит round trip через три платформы; смена публичной 0.x имеет миграцию либо явный экспорт для перехода, без тихой потери данных.
|===

== Сквозной сценарий
Нарисовать замкнутый контур из линий и дуг, добавить окружность и вспомогательную геометрию,
наложить ограничения/размеры, проверить DOF, перетащить допустимую точку, добавить конфликт и увидеть откат,
выполнить Undo/Redo, сохранить, переоткрыть на другой платформе и экспортировать DXF.
Отдельные критерии покрываются репрезентативными эскизами, а не одним искусственным примером.

== Не входит в 0.1
3D и OCCT, сборки, производственные чертежи, Python-макросы, эллипсы, сплайны, offset и массивы.
Полнота проецирования геометрии 3D, текстовых контуров и подложек относится к 1.0.

== Публикация
Обязательные платформы: Android ARM64, Linux/Windows x86-64.
Известные дефекты заявленных сценариев, неверная геометрия и потеря данных блокируют релиз.
Численные budgets и минимальные ОС определяются проверками xref:roadmap.adoc[], не выдумываются заранее.
