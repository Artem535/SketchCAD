= Product Vision
:toc:

Согласовано с пользователем 7 октября 2026 года по итогам интервью Q1–Q40.
Это целевое описание продукта, а не заявление о реализованных возможностях.

== Продукт и аудитория
SketchCAD — параметрический механический CAD с дополнительным прямым редактированием.
Основная аудитория: индивидуальные инженеры и небольшие конструкторские бюро.
Задачи 3D-печати покрываются внутри инженерного сценария.
Цель 1.0: точные детали, небольшие сборки, производственные чертежи и обмен с другими CAD.

== Платформы и работа
Android-планшеты ARM64, Linux и Windows x86-64 — обязательные платформы начиная с 0.1.
Android поддерживает полный функционал целевого релиза; отдельного урезанного мобильного продукта нет.
Касание и стилус — основные способы ввода на планшете; мышь и клавиатура также поддерживаются.
Давление пера не требуется. Desktop использует мышь и клавиатуру.
Формат проектов и функции общие для всех платформ.
Полный цикл работы доступен локально, без аккаунта и интернета.

Русский и английский обязательны для UI и основных пользовательских руководств.
Идентификаторы API и формат проекта не зависят от локализации.

== Архитектурные основы
C++20, Google C++ Style, snake_case; Qt 6 Quick/QML; CMake/Ninja; vcpkg manifest.
Собственная Qt-free модель со стабильными ID; Ceres для constraints, Eigen для математики и Jacobian rank.
OCCT подключается после Sketcher для B-Rep и операций над телами.
Миллиметры — внутренняя единица длины. UI поддерживает миллиметры и дюймы.
Успех оптимизатора не доказывает выполнение ограничений: нужны residual checks и транзакционный rollback.
DOF исключает временные drag/stabilization residuals.

== Модель распространения
Официальное приложение бесплатно и полнофункционально; pay what you want означает добровольную поддержку.
Выбран source-available подход: AGPL и permissive-лицензия отклонены.
Предполагается запрет сторонней продажи сборок, платного доступа и включения в платные комплекты без отдельного разрешения.
Бесплатные изменённые сборки разрешаются с соответствующими исходниками, сохранением авторства и отметкой неофициальности.
Коммерческое проектирование, закрытые модели/чертежи и закрытые пользовательские макросы разрешаются.
Обучение и поддержка могут быть платными, если само приложение получается независимо и бесплатно.

Это согласованная политика, НЕ вступивший в силу текст лицензии.
До юридического ревью нельзя объявлять репозиторий лицензированным на этих условиях.
Для документации выбрана CC BY 4.0; текст и notices ещё требуют оформления.
Для внешних contributions требуется соглашение, позволяющее менять лицензию и выдавать отдельные разрешения без обязательной передачи авторства.

== Выпуски
0.1 — законченный 2D Sketcher. 1.0 — конечный набор возможностей из xref:scope-1.0.adoc[].
Промежуточные версии 0.x — полезные публичные релизы с отдельными законченными сценариями.
Сроки и номера после 0.1 не обещаны; назначаются после декомпозиции и spikes.

== Проверяемый результат
* V-01: полный заявленный сценарий релиза выполняется на каждой из трёх платформ без аккаунта и сети.
* V-02: один проект переносится между платформами без потери поддерживаемых сущностей и параметров.
* V-03: интерфейс и основные руководства доступны на русском и английском.
* V-04: добровольный платёж не открывает скрытые функции и не требуется для редактирования/экспорта.
