= Backlog 0.1: спецификации задач
:toc:

Декомпозиция согласованного Scope 0.1, 7 октября 2026 года. Это задачи на реализацию, не готовая реализация.
Issue #1 остаётся историей rectangle demo. Задачи ниже создаются отдельно; статусы planned не означают дефект.
Готовность ready означает отсутствие внутренних зависимостей, но не наличие внешнего устройства/юриста.

== Общие границы
Qt-free core, stable IDs/mm, Ceres/Eigen и vcpkg; no OCCT/Python/3D в 0.1.
Каждая команда transactional; hard residuals проверяются; drag residuals исключаются из DOF.
Для каждого инкремента: уточнить specification/interface -> issue/labels -> RED -> implementation -> full relevant GREEN/runtime evidence -> review.
Пути файлов ниже являются предлагаемым разделением ответственности; изменение интерфейсов фиксируется в спецификации до кода.
Тест-план описывает наблюдаемое поведение; реализация не должна подменять независимые oracle проверками своих же вычислений.
