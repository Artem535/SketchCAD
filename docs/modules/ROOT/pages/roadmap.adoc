= Roadmap и условия выпуска
:toc:

== Состояние
Этап 0: rectangle demo на Qt Quick/Ceres с размерами, переносом, anchor и rollback.
Desktop Release build, 8 CTest checks, QML interaction/smoke и screenshot проверены в предыдущем запуске.
Это не 0.1 и не Android readiness. Историческая issue #1 покрывает прототип.

Это владельцы ролей, а не назначенные люди. Технические факты исследует агент; consequential choices возвращаются пользователю.

== Release gates
* Нет известных дефектов заявленных сценариев, неверной геометрии или потери данных.
* Core, UI/runtime, файлы и независимый обмен проверены отдельно.
* Android проверен APK и реальным устройством; desktop tests недостаточны.
* Публичные 0.x обеспечивают миграцию либо явный export transition; перед migration есть backup.
* Полный suite, CI, platform artifacts, RU/EN руководства и release limitations актуальны.
* Distribution/license obligations закрыты до публикации сборок.

== Следующий шаг после ревью документов
Декомпозировать 0.1 в отдельные tracked increments: общая Sketch model и ссылки;
редактирование; constraints/dimensions/diagnostics; transactions/Undo;
project storage; DXF; Android/Windows; release validation.
Для каждого: Antora acceptance -> issue -> labels -> RED -> implementation -> GREEN/runtime evidence.
Этот документ не создаёт issues автоматически и не разрешает обходить спецификацию.
