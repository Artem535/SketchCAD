= F01 implementation plan
:toc:

For agentic workers: use `superpowers:executing-plans` for inline execution or

Follow the tasks in order; read xref:project-format.adoc[] before implementing.

Goal:: Preserve a complete editable sketch across sessions through safe, versioned local files.
Architecture:: Validated Qt-free snapshots and a strict JSON codec; Qt local I/O with atomic replacement;
a file-command coordinator gates document replacement and window close.
Stack:: C++20, Ceres/Eigen, reflect-cpp from vcpkg, Qt Quick Dialogs, QSaveFile, GoogleTest and Qt Test.
Spec:: xref:project-format.adoc[] and xref:adr-0005-project-format.adoc[]. Issue #13.
Status:: Plan for review, 18 October 2026. No implementation started.

== Global constraints

* Schema 1, UTF-8 JSON, `.sketchcad`, units mm and radians; strict field/type validation.
* uint64 identity/revision fields are canonical decimal strings; zero next_id denotes exhausted allocation.
* 64 MiB input, 200,000 combined records, maximum JSON nesting depth 16.
* Persist every model field and the ID watermark; never serialize C++ enum ordinals or Qt types.
* Do not re-solve geometry during load; evaluate hard residuals using existing tolerances, exclude reference dimensions.
* Preserve the previous file and current document on I/O failure; mark saved only after QSaveFile commit.
* No persisted Undo history, autosave, camera/settings, network references or Android storage-provider claim.
* Follow Google C++ style, snake_case functions/variables and `Refs #13` commits. Record RED/GREEN in issue #13.
* Prefix shell commands with `rtk`; configure separate build directories for the actual host environment.

== Review focus

* A malformed field hidden in a large otherwise-valid file must reject the entire candidate (task 2).
* Stale selection or an in-flight gesture must not modify a newly opened document (tasks 1 and 4).
* A file picker cancellation after Save must not silently discard a dirty untitled project (task 4).
* A partial write or failed commit must preserve destination bytes and active path (task 3).
* Large IDs and near-limit revisions must remain exact and must never wrap during subsequent edits (tasks 1 and 2).

`tests/sketch_controller_test.cpp`, `tests/qml_test.cpp` and project documentation/handoff.

Interfaces consumed: tasks 1–3. ProjectSession owns no Sketch; it references the controller's existing Document.
Expose to QML through a separate `project` context object (register it in the app and QML test harness):

* Properties: `QString display_name`, `QUrl file_url`, `bool dirty`, `bool busy` with state-change notifications.
* Invokables: `request_new()`, `request_open()`, `request_save()`, `request_save_as()`, `request_close()`,
  `answer_unsaved(QString choice)` (save/discard/cancel), `accept_file(QUrl)`, `cancel_file()`.
* Signals: `ask_unsaved()`, `choose_open()`, `choose_save(QUrl suggested_url)`, `close_ready()`,
  `error(QString key)` and `document_replaced()`.
* `document_replaced()` tells SketchController to reset ToolSession/selection/previews and fit the new geometry.
  Never replace the referenced Document object itself: ToolSession retains a valid reference.
* Cancel active document gestures and clear uncommitted drawing state before file commands. Repeated requests
