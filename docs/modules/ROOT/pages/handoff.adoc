== Идея и согласованный продукт

SketchCAD — параметрическая механическая CAD-система для индивидуального инженера и небольшого бюро. Android-планшет — основной сценарий; Linux и Windows также обязательны. Работа offline, без обязательного аккаунта, с переносимыми проектами, интерфейсом и руководствами на русском и английском. Касание, стилус, мышь и клавиатура; давление стилуса не является обязательной зависимостью.

* Версия 0.1 — самостоятельный полезный 2D Sketcher: рисование, ограничения, размеры, диагностика, Undo/Redo, сохранение/восстановление, DXF, пакеты трёх платформ. Полный перечень и критерии — xref:scope-0.1.adoc[].
* Версия 1.0 — весь согласованный продукт: эскизы, параметрические детали и несколько тел, direct editing, сборки, ассоциативные производственные чертежи, обмен файлами, Python-макросы. Это целевой объём, а не текущая готовность.
* После 1.0: CAM, FEA, свободные поверхности, листовой металл, AI, облако, фотореалистичный rendering.

В 1.0 входят extrude/revolve/sweep/loft, boolean, fillet/chamfer, shell/draft/holes, mirror/patterns; история и устойчивые ссылки при перестроении. Сборки: связи, подсборки, пересечения, BOM; физическая симуляция не входит. Для чертежей нужна явная ограниченная матрица поддерживаемых ЕСКД/ISO. Форматы: STEP/IGES, STL/3MF, DXF/PDF; точную import/export матрицу уточнять по спецификации, не обещать восстановление истории из STEP. Ориентир масштаба сборок — 100 уникальных деталей / 500 компонентов, измеримые бюджеты после выбора устройств.

Python: встроенный CPython, стандартная библиотека и собственный API; макрос создаёт обычные операции истории. Сначала Android spike. Произвольные pip-пакеты и пользовательские Python features, исполняемые при каждом rebuild, не обещаны.

== Стек и инженерные границы

C++20, CMake/Ninja, Qt Quick/QML, Ceres/Eigen, vcpkg manifest с baseline `1600ce2ba1b6b621bfc5a31a785c4963b817a1c7`. Qt — установленный SDK. OCCT запланирован для моделирования, сейчас отсутствует.

Core эскиза и solver независимы от Qt/OCCT. Stable IDs, миллиметры, finite validation, транзакционные операции и rollback. Сходимость Ceres не означает удовлетворение ограничений: проверять каждый hard residual. Drag/stabilization residual исключать из DOF. Стиль Google C++, snake_case. GoogleTest для core, Qt Test для UI.

Каждое изменение поведения: Antora с acceptance criteria → GitHub issue со ссылкой → type/area/status labels → тесты и ожидаемый RED → реализация → полный относящийся набор тестов → evidence/limitations в issue. Документационный handoff не добавляет поведения.

== Лицензирование

Пользователь отказался от AGPL: требуется запрет сторонней продажи сборок и платного доступа без письменного разрешения. Закрытые пользовательские CAD-проекты, коммерческое проектирование и собственные макросы разрешены. Бесплатные forks требуют соответствующего исходного кода, attribution и маркировки неофициальной версии. Отдельные услуги поддержки, обучения и проектирования разрешены при независимом бесплатном доступе к программе. Официальное распространение бесплатно; пожертвования необязательны.

`LICENSE.draft.md` — source-available проект текста, *не вступившая в силу лицензия*. Требуется юридическая проверка, данные правообладателя и принятие текста. Документация планируется CC BY 4.0; contributor agreement позволяет перелицензирование без передачи авторства. Сторонние лицензии сохраняются. Источник решения: xref:licensing.adoc[], issue #2. Не объявлять проект open-source под AGPL и не внедрять платежи.

== Реализовано в ветке PR #20

=== Прототип прямоугольника — issue #1

`b4145e9`: Ceres solver, размеры, свободный перенос, фиксация origin, отклонение противоречащей ширины, finite validation и rollback. Qt controller, QML Canvas, управление размерами/фиксацией/drag, реальные QML acceptance tests и smoke/screenshot режимы. Это preset demo, а не общий Sketcher.

=== Общая модель эскиза — issue #4

`c2a9f54 feat: add validated Qt-free sketch model for #4`.
Основные файлы: `include/sketchcad/sketch.h`, `src/sketch.cpp`, `tests/sketch_test.cpp`; спецификация xref:sketch-model.adoc[].

Точки, линии, окружности и дуги; shared point references; construction flag; CRUD; атомарная валидация; value snapshots; polyline/rectangle helpers. EntityId — uint64, удалённые IDs не переиспользуются, high watermark сохраняется при присваивании snapshots. Удаление точки, на которую есть ссылки, отклоняется. Дуга: центр, положительный радиус, finite start/signed sweep в радианах. Детальный контракт — в спецификации.

Это только модель. Общие constraints/solver/DOF, document commands, Undo/Redo, файлы и подключение модели к QML ещё не реализованы. UI по-прежнему показывает preset rectangle.
