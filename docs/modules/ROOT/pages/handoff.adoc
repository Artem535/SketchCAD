== Краткий контекст

SketchCAD — открытый проект параметрической CAD-системы, ориентированной прежде всего на Android-планшеты и работу касанием. Начать нужно с удобного 2D Sketcher, затем перейти к построению объёмных деталей. Распространение предполагается по модели pay what you want. Публичность репозитория не означает, что выбрана лицензия: лицензия и платёжная интеграция пока не определены.

Пользователь выбрал подход Qt Quick + собственная модель эскиза + Ceres/Eigen + OCCT. Затем отдельно потребовал использовать vcpkg. Не возвращаться к FetchContent для зависимостей.

== Архитектурная идея

[source,text]
----
Qt Quick / QML
        |
QObject Controller
        |
Sketch Model (Qt-free, stable IDs, millimeters)
        |
Constraint Engine
  - build problem
  - solve on a copy
  - validate each hard residual
  - commit or rollback
  - later: DOF / redundancy / conflict diagnosis
        |
Ceres + Eigen
        |
Solved sketch
        |
Future: OcctProfileBuilder -> Wire -> Face -> Extrude / Revolve / Boolean
----

Эскиз хранит параметры, а не OCCT topology. OCCT должен получать решённый профиль через отдельный конвертер. Core не должен зависеть от Qt или OCCT. Это разделение должно облегчить будущие Undo/Redo и сериализацию; сами они ещё не реализованы и не специфицированы подробно.

Ceres — оптимизатор нелинейных least squares, а не готовый CAD constraint engine. Его успешная сходимость не доказывает выполнение ограничений. Нужны проверка residual каждого обязательного ограничения, транзакционность и собственная диагностика.

Перетаскивание общего эскиза в будущем предполагает временную мягкую drag-цель, warm start и ограниченный бюджет итераций. Мягкая цель не должна нарушать жёсткие ограничения. Нельзя включать drag/stabilization residual в расчёт DOF. Цель плавного взаимодействия обсуждалась, но измерений производительности и обещания 60 FPS нет.

== Первый прототип: согласованный объём

Проверить пресет прямоугольника:

* Горизонтальные и вертикальные стороны, ширина 50 мм, высота 30 мм.
* Без фиксации его можно переносить с сохранением размеров.
* Фиксация нижнего левого угла в (0,0) блокирует перенос.
* Противоречащая ширина 60 мм при исходной 50 мм отклоняется.
* После ошибки сохраняются прежняя геометрия и состояние фиксации.
* Нулевые, отрицательные и нечисловые/бесконечные размеры отклоняются.
* QML отображает изменения модели и статус решения.

В общей математической модели свободный прямоугольник имеет две поступательные DOF, зафиксированный — ноль. В текущем инкременте численный анализ DOF НЕ реализован и интерфейс его не показывает.

Это preset rectangle demo. Произвольное рисование линий, общая система сущностей и ограничений, круги/дуги, distance/perpendicular constraints, диагностика конфликтующих constraint IDs и OCCT остаются следующими этапами. Некорректные пользовательские ID пока нельзя подать: публичный API произвольных сущностей отсутствует.
